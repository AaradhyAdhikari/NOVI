# Novi Chrome extension

Lets Novi (running on this laptop) open, read, fill and click pages in your everyday Chrome when
you ask her by voice. It talks only to Novi on this laptop (ws://127.0.0.1), and only after you
paste the pairing code. Novi asks before final submits, never pays, never types passwords.

Install once:
1. Open `chrome://extensions` and turn on **Developer mode** (top right).
2. Click **Load unpacked** and pick this `extension` folder inside your Novi folder.
3. Click the Novi icon (puzzle piece → pin it), paste the code from Novi → Settings → Browser, Save.
